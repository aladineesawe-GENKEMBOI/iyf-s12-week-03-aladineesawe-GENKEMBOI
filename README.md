## 💻 Terminal Skills Practised

During this week, I practised:

* Navigating directories using `cd`.
* Creating folders using `mkdir`.
* Creating files using `touch`.
* Copying files using `cp`.
* Moving and renaming files using `mv`.
* Removing files and folders using `rm` and `rmdir`.
* Finding files using `find`.
* Searching file contents using `grep`.
* Counting lines using `wc`.
* Viewing command history using `history`.
* Creating Bash scripts.

## 🔀 Git and GitHub Skills

I practised:

* Initialising and managing repositories.
* Cloning repositories.
* Staging and committing changes.
* Pushing and pulling changes.
* Creating and merging branches.
* Resolving merge conflicts.
* Working with remote repositories.
* Using `.gitignore`.
* Publishing websites using GitHub Pages.
